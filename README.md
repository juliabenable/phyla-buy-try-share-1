# Phyla Buy, Try, Share: prototypes

Live pages: https://juliabenable.github.io/phyla-buy-try-share-1/

| Page | Built file | Readable source |
|---|---|---|
| Brand Portal page | `brand.html` | `src/brand.html` (+ `src/rights-cs.css`, `src/assets/`) |
| Creator mobile flow | `creator.html` | `src/creator.html` (+ `src/m/` Figma assets) |
| Creator mobile flow v2 (Nov 25 designs) | `creator-v2.html` | `src/creator-v2.html` |
| Design review list | `design-review.html` | same file |
| Build handoff | `handoff.html` | same file |
| Study | `index.html` | same file |

The built files inline all CSS and images, so they are large. Read and edit the files in `src/`, then run `python3 build.py` to rebuild.

These are static HTML prototypes (no framework). Amine's Figma is the source of truth for creator-side visuals.
